# Community Sports Club Player and Volunteer Management System

ENSE707 Software Quality Assurance group project.

## Description

This project is a management system for community sports clubs, covering:

- Player registration
- Volunteer coordination
- Team allocation
- Attendance tracking
- Admin reporting
